## [1.0.19] - 2024-12-27

### 🚨 КРИТИЧЕСКОЕ ИСПРАВЛЕНИЕ
- **Исправлено отключение из комнат через час** - пользователи больше не вылетают из голосовых комнат после ~60 минут общения

### 🔧 Технические исправления
- **Heartbeat механизм** - исправлен и оптимизирован (каждые 25 секунд)
- **Presence Check** - добавлена проверка присутствия в комнате (каждые 2 минуты)
- **Firebase timestamp** - исправлен импорт (Date.now() вместо ServerValue.TIMESTAMP)
- **Автоматическое переподключение** - улучшена логика восстановления соединения

### ⚡ Улучшения
- Автоматическое восстановление записи пользователя при сбоях
- Защита от случайного удаления из комнаты
- Улучшенный мониторинг статуса соединения Firebase
- Оптимизированы интервалы проверки соединения

### 🎯 Результат
- **Неограниченное время общения** - можно находиться в комнате сколько угодно
- **Автоматическое восстановление** - при временных сбоях соединения
- **Стабильность** - защита от Firebase timeout и network issues

## [1.0.14] - 2025-11-15

### 🎉 Новые возможности
- **Интеграция Catbox.moe** - файлы теперь загружаются на бесплатный хостинг вместо Firebase
- **Увеличен лимит файлов** - до 50MB (вместо 10MB)
- **Оптимизация трафика** - Firebase хранит только URL вместо base64

### ⚡ Улучшения
- Добавлен прогресс загрузки файлов
- Улучшена обработка ошибок загрузки файлов
- Добавлен crossOrigin для корректной загрузки с внешних доменов
- Оптимизирована отправка файлов (без base64 конвертации)

### 🐛 Исправления
- Исправлена загрузка больших файлов
- Улучшена стабильность отправки файлов
- Исправлены ошибки отображения файлов у других пользователей

### 📝 Технические изменения
- Добавлен модуль `file-upload.js` для работы с Catbox API
- Обновлен `chat.js` для поддержки URL вместо base64
- Увеличен `MAX_FILE_SIZE` до 50MB в константах
- Удалена поддержка старого формата base64

### ⚠️ Breaking Changes
- Старые сообщения с base64 файлами больше не поддерживаются
- Требуется интернет соединение для просмотра файлов
