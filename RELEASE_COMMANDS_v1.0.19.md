# Команды для создания релиза v1.0.19

## 1. Коммит изменений

```bash
git add .
git commit -m "Release v1.0.19: КРИТИЧЕСКОЕ ИСПРАВЛЕНИЕ - Отключение из комнат через час

🔧 Исправления:
- Исправлен механизм heartbeat (каждые 25 секунд)
- Добавлена проверка присутствия в комнате (каждые 2 минуты)  
- Исправлен импорт Firebase timestamp (Date.now() вместо ServerValue.TIMESTAMP)
- Добавлены вызовы heartbeat при переподключении
- Улучшено соединение с Firebase и автоматическое переподключение

🎯 Результат:
- Пользователи больше НЕ вылетают из комнаты через час
- Автоматическое восстановление при сбоях соединения
- Защита от случайного удаления записи пользователя

Fixes #heartbeat-disconnect-issue"
```

## 2. Создание тега

```bash
git tag -a v1.0.19 -m "Release v1.0.19 - КРИТИЧЕСКОЕ ИСПРАВЛЕНИЕ отключения из комнат

🚨 ВАЖНОЕ ОБНОВЛЕНИЕ:
Исправлена критическая проблема с автоматическим отключением пользователей 
из голосовых комнат через ~60 минут общения.

🔧 Ключевые исправления:
- Heartbeat механизм (25 сек)
- Presence check (2 мин)
- Firebase timestamp fix
- Автоматическое переподключение

✅ Теперь можно общаться в комнатах неограниченное время!"
```

## 3. Пуш в репозиторий

```bash
git push origin main
git push origin v1.0.19
```

## 4. Сборка приложения

```bash
npm run build:win
```

## 5. Создание релиза на GitHub

После пуша тега:

1. Перейдите на https://github.com/kosenkomaks1999-dotcom/vibechat/releases
2. Нажмите "Draft a new release"
3. Выберите тег: `v1.0.19`
4. Название релиза: `v1.0.19 - КРИТИЧЕСКОЕ ИСПРАВЛЕНИЕ: Отключение из комнат через час`
5. Описание: скопируйте содержимое из `CHANGELOG_v1.0.19.md`
6. Загрузите файл: `release/VibeChat-Setup-1.0.19.exe`
7. Отметьте как "Set as the latest release"
8. Нажмите "Publish release"

## 6. Автоматическая публикация (альтернатива)

Если настроен GitHub token:

```bash
npm run publish
```

Это автоматически:
- Соберёт приложение
- Создаст релиз на GitHub
- Загрузит установочный файл

## 7. Проверка релиза

После публикации:

### Базовая проверка:
1. ✅ Проверьте, что релиз виден на GitHub
2. ✅ Скачайте и установите новую версию
3. ✅ Проверьте автообновление в существующей версии

### Проверка исправления:
1. ✅ Войдите в комнату
2. ✅ Откройте консоль браузера (F12)
3. ✅ Убедитесь что появились сообщения:
   ```
   ✅ Heartbeat started (interval: 25s)
   ✅ Presence check started (interval: 2min)
   ```
4. ✅ Каждые 25 секунд должно появляться:
   ```
   🔄 Heartbeat: соединение обновлено
   ```
5. ✅ **ГЛАВНЫЙ ТЕСТ:** Оставьте приложение в комнате на 1-2 часа - пользователь должен остаться подключенным

## 8. Уведомление пользователей

После успешного релиза:

1. **Обновите README.md** с информацией о исправлении
2. **Создайте пост в Discussions** о важности обновления
3. **Уведомите активных пользователей** о критическом исправлении

## 9. Откат (если нужно)

Если что-то пошло не так:

```bash

# Удалить тег на GitHub

# Откатить коммит (если не запушен)

```
