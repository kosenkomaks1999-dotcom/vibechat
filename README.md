# VibeChat

Голосовой чат приложение на Electron с поддержкой видеозвонков, обмена сообщениями и файлами.

## ✨ Возможности

- 🎤 **Голосовые звонки** с WebRTC
- 💬 **Текстовый чат** в реальном времени
- 📁 **Обмен файлами** (изображения, аудио, видео)
- 👥 **Система друзей** с уведомлениями
- 🎨 **Настраиваемый интерфейс** (фоны, темы)
- 🔔 **Уведомления** о событиях
- 🔒 **Безопасное подключение** через Firebase
- 🎨 **Whiteboard** для совместного рисования
- 📟 **Встроенная консоль** разработчика

## 📥 Установка

### Для пользователей:
1. Скачайте последнюю версию из [Releases](https://github.com/kosenkomaks1999-dotcom/vibechat/releases)
2. Запустите установщик
3. Следуйте инструкциям на экране

## 🛠️ Технологии

- **Electron** 28.3.3 - Desktop framework
- **Firebase** Realtime Database - Backend
- **WebRTC** (Simple Peer) - P2P видео/аудио
- **Vanilla JavaScript** - Frontend (модульная архитектура)
