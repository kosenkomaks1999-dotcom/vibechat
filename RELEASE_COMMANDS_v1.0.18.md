# Команды для создания релиза v1.0.18

## 1. Коммит изменений

```bash
git add .
git commit -m "Release v1.0.18: Исправление вылета из комнаты через час

- Улучшен механизм heartbeat (каждые 25 секунд)
- Добавлена проверка присутствия в комнате (каждые 2 минуты)
- Улучшено соединение с Firebase
- Оптимизирован мониторинг соединения

Fixes: Пользователи вылетали из комнаты примерно через час разговора"
```

## 2. Создание тега

```bash
git tag -a v1.0.18 -m "Release v1.0.18 - Исправление вылета из комнаты

Критические исправления:
- Улучшен heartbeat механизм
- Добавлена проверка присутствия
- Улучшено Firebase соединение
- Оптимизирован мониторинг"
```

## 3. Пуш в репозиторий

```bash
git push origin main
git push origin v1.0.18
```

## 4. Сборка приложения

```bash
npm run build:win
```

## 5. Создание релиза на GitHub

После пуша тега:

1. Перейдите на https://github.com/kosenkomaks1999-dotcom/vibechat/releases
2. Нажмите "Draft a new release"
3. Выберите тег: `v1.0.18`
4. Название релиза: `v1.0.18 - Исправление вылета из комнаты`
5. Описание: скопируйте содержимое из `CHANGELOG_v1.0.18.md`
6. Загрузите файл: `release/VibeChat-Setup-1.0.18.exe`
7. Нажмите "Publish release"

## 6. Автоматическая публикация (альтернатива)

Если настроен GitHub token:

```bash
npm run publish
```

Это автоматически:
- Соберёт приложение
- Создаст релиз на GitHub
- Загрузит установочный файл

## Проверка

После публикации:
1. Проверьте, что релиз виден на GitHub
2. Скачайте и установите новую версию
3. Проверьте автообновление в существующей версии
4. Протестируйте исправление (оставайтесь в комнате 1-2 часа)

## Откат (если нужно)

Если что-то пошло не так:

```bash
# Удалить тег локально
git tag -d v1.0.18

# Удалить тег на GitHub
git push origin :refs/tags/v1.0.18

# Откатить коммит (если не запушен)
git reset --soft HEAD~1
```
