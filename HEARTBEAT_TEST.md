# Тест функций Heartbeat и Presence Check

## Что было исправлено:

1. **Исправлен импорт Firebase timestamp** - заменен `firebase.database.ServerValue.TIMESTAMP` на `Date.now()`
2. **Добавлены вызовы heartbeat в переподключение** - функции `startHeartbeat()` и `startPresenceCheck()` теперь вызываются при `attemptReconnect()`
3. **Функции уже вызываются при входе в комнату** - в callback `onJoined` RoomsManager

## Как проверить что исправление работает:

1. **Войдите в комнату** - в консоли должны появиться сообщения:
   ```
   ✅ Heartbeat started (interval: 25s)
   ✅ Presence check started (interval: 2min)
   ```

2. **Каждые 25 секунд** в консоли должно появляться:
   ```
   🔄 Heartbeat: соединение обновлено
   ```

3. **Оставьте приложение открытым на 1-2 часа** - пользователь должен остаться в комнате

## Логика работы:

### Heartbeat (каждые 25 секунд):
- Обновляет `lastActive` timestamp в Firebase
- Обновляет `onDisconnect()` handler для продления соединения
- Предотвращает автоматическое отключение Firebase через 60 минут

### Presence Check (каждые 2 минуты):
- Проверяет существование записи пользователя в комнате
- Если запись исчезла - автоматически восстанавливает её
- Защищает от случайного удаления записи

### Firebase соединение:
- Настроено автоматическое переподключение в `firebase.js`
- Мониторинг `.info/connected` для отслеживания статуса
- Явный вызов `database.goOnline()` при инициализации

## Если проблема остается:

1. **Проверьте консоль браузера** - должны быть сообщения о heartbeat
2. **Проверьте Firebase правила** - убедитесь что пользователь может обновлять свою запись
3. **Проверьте интернет соединение** - нестабильное соединение может вызывать отключения
4. **Проверьте лимиты Firebase** - возможно достигнут лимит операций чтения/записи

## Дополнительные рекомендации:

1. **Используйте стабильное интернет соединение**
2. **Не закрывайте вкладку браузера** - это прерывает соединение
3. **Обновите браузер** - старые версии могут иметь проблемы с WebRTC
4. **Проверьте настройки энергосбережения** - они могут приостанавливать JavaScript
